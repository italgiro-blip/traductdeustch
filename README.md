# \# 🇩🇪 Traductor Alemán B1 



Una aplicación web ligera e interactiva diseñada para estudiantes de alemán de nivel A1/B1. Permite traducir textos de español a alemán (y viceversa), escuchar la pronunciación nativa y dictar frases por voz, todo directamente desde el navegador y sin necesidad de crear cuentas ni configurar APIs complejas.



\## 🚀 Características principales



\* \*\*Traducción rápida:\*\* Utiliza un diccionario local para expresiones cotidianas y una API pública (\*MyMemory\*) para el resto de oraciones.

\* \*\*Reconocimiento de voz (Dictado):\*\* Permite hablarle a la aplicación para que escriba el texto automáticamente (compatible con navegadores basados en Chromium como Chrome o Edge).

\* \*\*Síntesis de voz (Audio):\*\* Escucha la pronunciación correcta del texto traducido con acento nativo.

\* \*\*Orientación Gramatical:\*\* Muestra sugerencias y recordatorios útiles orientados al nivel B1 (colocación de verbos, géneros y casos).

\* \*\*100% Responsive:\*\* Diseñado con Tailwind CSS para adaptarse perfectamente tanto a computadoras como a teléfonos móviles.



\## 📱 Uso en dispositivos móviles

La aplicación es extremadamente ligera (apenas unos pocos kilobytes) y no requiere instalación. Puedes abrirla directamente desde el navegador de tu celular y añadirla a la pantalla de inicio si lo deseas.



\## 🛠️ Tecnologías utilizadas

\* \*\*HTML5\*\*

\* \*\*Tailwind CSS\*\* (vía CDN)

\* \*\*JavaScript\*\* (Vanilla JS con Web Speech API y Fetch API)



\## ⚙️ Cómo usarlo localmente

1\. Clona este repositorio o descarga el archivo `index.html`.

2\. Abre el archivo `index.html` en cualquier navegador web moderno.

3\. ¡Listo! Ya puedes empezar a traducir y practicar.
